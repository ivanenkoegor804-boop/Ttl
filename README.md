# Летопись династии

Историческая стратегия о Древней Руси (862–1480). Озвучка, иллюстрации и портреты встроены в `index.html`.

## Как выложить с iPhone и поставить на домашний экран

1. В «Файлах» нажми на `letopis-github.zip`, он распакуется в папку.
2. На github.com (в Safari) создай репозиторий: **New** → название, например `letopis` → **Public** → **Create repository**.
3. **Add file → Upload files → choose your files**: выбери все файлы из папки (`index.html`, `sw.js`, `manifest.webmanifest`, три иконки `.png`, `README.md`) → **Commit changes**.
4. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main`, папка `/ (root)` → **Save**. Через 1–2 минуты появится ссылка вида `https://ТВОЙ-НИК.github.io/letopis/`.
5. Открой ссылку в Safari → кнопка **Поделиться** → **На экран «Домой»**.

## Важно
- После первого запуска игра работает без интернета.
- Сохранение в иконке на экране и сохранение в Safari хранятся отдельно, друг друга они не видят.
- Чтобы обновить игру, загрузи новые файлы поверх старых (**Upload files**). Приложение обновится при следующем открытии с интернетом.
